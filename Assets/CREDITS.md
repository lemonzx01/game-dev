## Rules for Adding New Assets
1. ระบุชื่อไฟล์, ขนาด, ชื่อผู้สร้าง, URL ต้นทาง (หรือคำสั่งสร้าง) และประเภท License ให้ชัดเจนในตารางด้านบนก่อนนำเข้าโปรเจกต์
2. ตรวจสอบความเข้ากันได้ของ License กับการ build/เผยแพร่เกมบน Windows (เช่น CC0, MIT, CC-BY พร้อมข้อความเครดิต, หรือสิทธิซื้อขาด)
3. ห้ามคัดลอกภาพหรือ Sprite จากเกมอื่นหรือชุดภาพที่ไม่ทราบที่มาโดยเด็ดขาด
