# Google Antigravity entry instructions

This portable instruction file is intended to be explicitly read via START_HERE.md; it does not claim automatic discovery by any particular Antigravity version.

Read AGENTS.md and follow its rules as the shared authority. Read GAME_DESIGN.md, ARCHITECTURE.md, TASKS.md and PROGRESS.md as directed there.

Antigravity is one of three equal developers (see AGENTS.md "Team"). It has no fixed role: it may design, implement Simulation or Godot code, test, review, fix and take over any task under the same claim, branch, test and handoff rules. Keep context focused to conserve quota.
