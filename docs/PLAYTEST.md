# รายการเช็กเล่นทดสอบ (T018), สำหรับเจ้าของโปรเจกต์ 15–30 นาที

เปิดเกมด้วย `Play.cmd` หรือ `build/windows/FantasyWorldSimulator.exe` ทั้งโฟลเดอร์ ปุ่มทั้งหมดอยู่ใน `docs/PLAYING.md`
เจออะไรแปลกให้จด **เวลาในเกม (มุมซ้ายบน), tick (กด F3), สิ่งที่เห็น และสิ่งที่คาดว่าควรเป็น** ในตารางท้ายไฟล์
ถ้ากด F5 save ไว้ก่อนเจอปัญหาได้ ไฟล์ save จะช่วยให้ทำซ้ำได้ตรงเป๊ะ

## ช่วงที่ 1: ดูโลกเฉย ๆ (5 นาที, ความเร็ว ×1–×2)
- [ ] เกมเปิดมาที่เมือง Ashford ตอนกลางคืน และฟ้าค่อย ๆ สว่างขึ้นตามนาฬิกาในเกม
- [ ] ชาวเมืองเดินลื่น หันซ้ายขวาตามทางที่เดิน ทำงาน (ท่าจอบ) และนั่งอ่านหนังสือที่กลางเมืองเมื่อว่าง
- [ ] สัตว์ (แกะ กวาง กระต่าย หมาป่า) กิน ดื่ม หนี ล่า และตายเป็นซาก ดูได้ด้วยตาว่ามีเหตุผล
- [ ] แผงเมืองมุมขวาบน: อาหาร ไม้ และเหรียญเปลี่ยนตามที่เห็นคนเก็บของเข้าคลัง
- [ ] คลิกตัวละครแล้ว inspector บอกความหิว ความกระหาย สุขภาพ งาน ทักษะ (และ mana ถ้าใช้เวทได้) กด F เพื่อติดตาม
- คำถามความสนุก: ดูแล้วอยากดูต่อไหม ตรงไหนน่าเบื่อหรืออ่านยาก

## ช่วงที่ 2: เร่งเวลา (5–10 นาที, ×4–×8)
- [ ] เกมไม่กระตุกหนัก (F3 ดู backlog) และตัวละครไม่วาร์ปแปลก ๆ
- [ ] ผ่านวันและฤดู: พืชและอุณหภูมิเปลี่ยน
- [ ] มีการเกิด แก่ ตาย และประชากรไม่หายหมดหรือล้นจนเกินไปในหนึ่งปีเกม
- [ ] ถ้ามีคนอ่านหนังสือจบ (ใน inspector บอก books 1 finished) เขาควรใช้เวทได้ (mana)

## ช่วงที่ 3: God mode (5–10 นาที, กด G)
- [ ] Q แล้ว Tab เลือกสัตว์ คลิกขวาเพื่อเสก ลองเสก **หมาป่าในเมือง**: ยามสู้ ชาวบ้านส่วนใหญ่หนี ส่วนคนกล้าที่อยู่กับเพื่อนอาจสู้กลับ
- [ ] Tab จนเจอ **Dragon** แล้วเสกใกล้เมือง: ยามสู้ เกิดแรงกระแทก ชาวบ้านหนี มังกรหันมาสู้คนที่ตีมัน
  - สังเกต: ยามคนใหม่ที่อาสาเข้าแทนจะเข้าไปสู้ต่อจนตายทีละคน (เป็นบั๊กที่รู้อยู่แล้ว ข้อ K1 ใน KNOWN_ISSUES)
- [ ] เสกกวางใกล้เมืองแล้วรอ: ชาวบ้านที่ว่างจะเอาอาหารไปป้อน (อาหารในคลังลด) สักพักกวางเป็นของเมือง (มีประกาย และบันทึกเหตุการณ์บอกว่า tamed)
- [ ] W แล้ว Tab เลือกพื้น ระบายน้ำหรือภูเขา: แผนที่เปลี่ยนทันที และถ้าระบายทับสัตว์ เกมจะไม่ยอมให้ทำ
- [ ] E เพื่อสร้างเมืองใหม่ มนุษย์หรือปีศาจ: เมืองใหม่ขาดของ อาจได้เห็นพ่อค้าจากเมืองเดิมเดินมาขาย

## ช่วงที่ 4: save และ load (2 นาที)
- [ ] F5 save แล้วเล่นต่อสักพัก จากนั้น F9 load: โลกกลับไปที่จุดที่ save ไว้ ทั้งตำแหน่ง คลัง และมังกร
- [ ] ปิดเกม เปิดใหม่ แล้ว F9: ได้โลกเดิม

## สิ่งที่อยากให้ตัดสิน (ความเห็นของเจ้าของ)
1. ความเร็วเริ่มต้นและระยะซูมเริ่มต้นพอดีไหม
2. ภาพตัวละครและภาพฉากตอนนี้ "ดีพอ" หรืออยากให้ทำ art pass ต่อ (บ้าน ถนน ไฟ)
3. มังกรควรโผล่เองในโลกไหม (ตอนนี้เสกได้จาก God อย่างเดียว)
4. อยากได้อะไรก่อน: สิงร่างตัวละคร (T020), สงครามระหว่างเผ่า หรือระบบอื่น
