## Design (ARCHITECTURE §4–§6)
- **Decision cadence:** each entity has one pending `Think` (discretionary work, priority 20), first staggered by `EntityId % ThinkIntervalTicks`, then every `ThinkIntervalTicks` (10), or `DangerThinkIntervalTicks` (2) while a threat is perceived. Thinks obey `DiscretionaryWorkBudget` (a count); the remainder carries forward in order. No decision runs per render frame.
- **Pipeline:** perceive (nearest feared living entity via a bucketed `SpatialGrid`, Chebyshev radius) → read vitals/fatigue → score candidates (integers) → order by (score desc, `ActionKind` asc) → first *feasible* candidate wins. Feasibility is checked lazily in that order, so pathing only runs when it matters.
- **Scores:** Flee 2000+ (closer = higher), Drink thirst×1.2, Eat hunger, Rest fatigue×0.9 (not while threatened), Wander 50. Start thresholds (Eat/Drink 300k, Rest 600k fatigue; rest ends at 50k) add hysteresis.
- **No oscillation:** a started non-idle action is committed for `CommitmentTicks` (30) and its kind gets `InertiaBonus` (150); danger always overrides commitment (interrupt).
- **Actions:** `ActionStep` is required work (priority 5) driven by per-entity tokens, so superseded steps/thinks are ignored. Eat/Drink walk a bounded BFS path (radius 8, ≤ 400 expanded cells; unreachable = infeasible), then call T004 `TryConsume`. Rest re-anchors fatigue and wakes at the computed recovery tick. Flee steps greedily away from the threat until safe or `FleeSteps`. Wander moves one tile using AI RNG stream 2.
- **Fatigue** is an elapsed-time anchor like vitals (rises awake, falls resting); it does not damage health yet.
- **Events:** `ActionStarted` (Actor, Target = threat, Reason = `ActionKind`). Snapshot rows carry the action in `EntityRow.Action`.
- **Test maps:** `SimulationOptions.Map` (`MapOverride.FromRows`) builds exact scenarios; map minimum size is now 2×2.
