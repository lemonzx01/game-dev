## Design (ARCHITECTURE §5, §9 M5)
- **Personality:** Bravery and Sociability (0–1000). Catalogued species roll them (RNG stream 4); newborns inherit the parents' mean ± `TraitJitter` (100). Uncatalogued species stay neutral (500), so older scenarios behave as before.
- **Emotion:** Fear (0–1000), an elapsed-time anchor that decays by `FearDecayPerTick`. Seeing a threat raises it (more when closer); being attacked sets it to 1000. Fear above `FearBlocksMatingAbove` blocks conception.
- **Decision effects:** Flee utility = proximity × (2000 − bravery)/1000 + fear/2, so bold animals ignore distant threats while timid ones flee early. Mate utility = 250 + sociability/4. Wandering avoids tiles within `DangerAvoidRadius` of danger remembered in the last `DangerMemoryTicks` (falls back to any allowed tile).
- **Working memory:** ≤ 64 `MemoryRecord`s per entity (FoundFood 100, SawThreat 300, Mated 500, WasAttacked 800, BecameParent 900 importance). The same kind/subject/place refreshes LastRelevantTick instead of duplicating. At the cap the lowest (importance, lastRelevantTick, id) is evicted.
- **Relationships:** ≤ 32 directional entries (affinity −1000..1000, familiarity), sorted by other id. The weakest (|affinity| + familiarity, lastTick, other id) is evicted. Reciprocal updates only when justified: mates both +200, mother ↔ child both +300; an attack changes only the victim's view (−600).
- **Durable history** (births, deaths, parentage) is separate from working memory and never evicted. `ReadEntityMind` is a read model for inspectors (not on `ISimulation`, A007 frozen) and never feeds knowledge back to NPCs.
- StateHash schema 8 (traits, fear anchor, memories, relationships, memory id counter, psyche config).

## Acceptance evidence (2026-11-24, Windows, SDK 10.0.404)
`dotnet test Tests/Simulation.Tests -c Release -m:1` → `57/57 test groups passed`, exit 0, ~10 s. T010 groups:
- Same inputs (starving deer on food, wolf penned in sight 11 steps away): bravery 900 → Eat, bravery 100 → Flee.
- Danger changes emotion: a fearless deer attacked by a wolf → fear ≥ 990, `WasAttacked` memory of the wolf, negative affinity toward it; the wolf gains no relationship (directional). Fear 1000 decays to 800 after 100 quiet ticks.
- Memory cap: 64 entries; duplicates refresh in place; a SawThreat evicts the lowest-id FoundFood; an older LastRelevantTick is evicted before a refreshed one.
- Relationship cap: 40 updates → 32 kept, strongest kept, weakest/oldest/lowest id evicted, sorted by id, directional.
- Durable history: with MemoryCap 2 the birth memory is evicted, but the birth milestone and the child's MotherId remain.
- Inheritance: children's traits within ±100 of the parents' mean; child → mother and mate ↔ mate bonds positive.
- Remembered danger east of a corridor → wandering never returns east over 200 ticks.
- Golden hash re-pinned (schema 7 → 8): tick 1 = `FDBA8DD1…540580`.
