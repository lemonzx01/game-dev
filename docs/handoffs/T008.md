## Design
- **Host-only controls** (`ObserverController`): Space pause/resume, `.` single step while paused, keys 1–4 speed ×1/×2/×4/×8 (`HostClock`), left click picks the nearest snapshot row, F follows the selection, Esc clears. None of these submit commands (A007 §3), and following never changes outcomes.
- **Inspector** (`InspectorPanel`): species, sex, stage, age, parents, position, hunger/thirst/health %, pregnancy, current action, bravery/sociability/fear, latest memories and strongest bonds via the bridge's read-only `Details` / `Mind`. For a dead animal it shows the durable record (death tick and cause), so history is retained. It refreshes only when the tick or the selection changes.
- **Event feed** (`EventFeed`): readable lines for births, deaths (cause, killer), attacks, rejected God commands, skipped minor events and lost event ranges (Gap); last 12 lines.
- **Bridge:** species catalog on, `StarterAnimals` (Main scene: 120 mixed deer/rabbit/sheep/wolf spread over the map through ordinary God spawn commands; 0 keeps the T007 single-entity opening), exposes `Clock`, `Details`, `Mind`, `History`, `SpeciesName`.
- **Renderer:** placeholder colour per species, grey for dead rows on their death tick, red outline on the selection; the camera starts zoomed to fit the whole map.
