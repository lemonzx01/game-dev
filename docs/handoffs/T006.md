## Design (ARCHITECTURE §6)
- **Spatial grid** (from T005): 8×8 buckets of living entities, updated on spawn, move and death; queries visit only overlapping buckets in ascending order. `NearbyIds(x, y, r)` adds the exact Chebyshev filter.
- **Path request queue:** Eat/Drink no longer search inside Think. Starting the action queues a `PathRequest(entity, kind, token)`; after the scheduler each tick, requests are served FIFO while the remaining node budget (`PathNodeBudgetPerTick`, default 4,000) covers a full search (`SearchNodeBudget`, 400). Searches are charged their actual expansions, so a tick never exceeds the budget and the ordered remainder carries forward. Stale requests (entity died, fled, re-requested) are dropped for free.
- **Search:** bounded BFS to the nearest stocked goal (multi-target: the nearest food/water tile, not a fixed point), radius 8. On a uniform 4-neighbour grid BFS gives the same shortest paths as A*. A* is deferred until a single-target move exists (guards, possession: T016/T020).
- **Unreachable:** no path → `PathFailed` event, the agent finishes the action and that need is infeasible for `UnreachableCooldownTicks` (100), so there are no infinite retries.
- **Blocked:** if the next path cell became impassable, the agent re-plans from its current position up to `MaxReplans` (2) times, then gives up.
- **God `SetTerrainCommand`** (new): changes one tile; rejected on tiles with resource nodes (`HasResource`) or when it would trap a living entity on an impassable tile (`Occupied`); `ReadMap()` returns the updated view. Terrain is already part of the hash.
- StateHash schema 5 (path queue, mind path/cooldown fields, new config).
