## Design & Thresholds (`DangerConfig`)
Default parameters in `Simulation/SimulationWorld.Danger.cs`:
- `OutmatchMultiplier = 3`
- `DefenseRadius = 10`
- `SupportRadius = 3`
- `AlarmDurationTicks = 160`
- `AlarmClearGraceTicks = 20`
- `AlarmLeaveMargin = 2`
- `GatherScore = 900`
- `GuardRetreatScore = 4100`
- `GuardSafeDistance = 6`
- `VillagerFleeDistance = 4`

Behavior summary:
1. **Deterministic integer threat assessment (`EstimateFighterStrength`, `IsOutmatchedAgainst`):**
   - Uses `AttackPower(fighter)`, skill bonus (`100 + 10 * Level(fighter, Skill.Combat)`), `atkConditionPct = 50 + 50 * Health / MaxHealth`, `durabilityPct = 30 + 70 * Health / MaxHealth`, and `100 / Math.Max(1, DamageTakenPercent)` in `Int128` via `ScalePercent`, clamped to `long.MaxValue` with no signed overflow.
   - `IsStrongThreat`: foe strength exceeds `(Int128)TradeCfg.GuardDamage * DangerCfg.OutmatchMultiplier`.
   - `AlliedDefenseVisitor` (`IGridVisitor`) scans `grid.QueryRange` within `Math.Max(TownCfg.Radius, DefenseRadius)` under `QuerySliceBudgetNow()`, summing willing defenders (`Job.Guard`, `fightingSameFoe`, `nearbyActor <= SupportRadius`, or `ralliedAtCentre` within `1`/`2` of town centre during alarm, plus adult sapient villagers with `Bravery >= CombatCfg.FightBackBravery`), applying `AlliedStrengthWithBonus` (`CombatCfg.MaxAllies`, `CombatCfg.AllyBonusPercent`) and short-circuiting immediately when `ourWithBonus * OutmatchMultiplier >= foeStrength`.
2. **Guard retreat & Town alarm (`RaiseTownAlarm`, `GatherStep`, `TickDangerAlarms`):**
   - When a guard faces an outmatching threat (`IsOutmatchedAgainst`), it raises/refreshes the town alarm (`EventKinds.TownAlarm = 230`), records `MemoryKind.SawThreat`, runs bounded `AlarmInterruptVisitor` to finish non-guard `Work`/`Read`/`Tame`/`Sleep`/`Rest` and impart `SawThreat` memory, and chooses `Gather (13)` (`GuardRetreatScore = 4100`) / `Flee` toward safety (`GuardRetreatStep` / `StepTowardTownCentre`), emitting `EventKinds.GuardRetreated = 231`.
   - Townsfolk inside `TownCfg.Radius` halt work/reading/taming/sleep/rest/mating during `AlarmUntil > now`, fleeing if the threat is within `VillagerFleeDistance` (`4`) or rallying via `ActionKind.Gather (13)` (`GatherScore = 900`).
   - `TickDangerAlarms` refreshes while the threat stays within `TownCfg.Radius + AlarmLeaveMargin`, then clears at `Math.Min(AlarmUntil, AlarmLastSeenTick + AlarmClearGraceTicks)` once the threat leaves or dies, emitting `EventKinds.TownAlarmEnded = 232`.
3. **Group defence (`ResolveCombatOrAlarmCandidates`, `ActiveTownStrongThreat`):**
   - Brave adult villagers within `TownCfg.Radius` join defenders once `!IsOutmatchedAgainst`, and rallying guards break `GatherStep` early to switch into `ActionKind.Defend` together.
4. **Danger memory avoidance:**
   - Survivors gain `MemoryKind.SawThreat` on alarm and (`Paths.cs`) `ActionKind.Work` (`Harvest`/`GatherFood`/`GatherWood`) avoids destinations matching `RemembersDangerNear` while `HasRecentDangerMemory` holds (alongside `T010` wander and `GatherStep`/`StepTowardTownCentre` avoidance).
5. **Small threats unchanged:**
   - Single wolf (`EstimateFighterStrength = 400_000`) stays well below `Guard` (`350_000 * 3 = 1_050_000`) and `IsStrongThreat` (`1_050_000`), so one guard still fights it alone without raising `TownAlarm`.
